# FlightAware MCP Server (Local)

Local implementation using stdio transport.

## Usage

```bash
npm install
npm run build
npm start
```

## Development

```bash
npm run dev  # Auto-rebuilds shared module
```

## Configuration

### Environment Variables

| Variable          | Required | Description                  |
| ----------------- | -------- | ---------------------------- |
| `AEROAPI_API_KEY` | Yes      | Your FlightAware AeroAPI key |
